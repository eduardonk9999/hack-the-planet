SQLi em 10 segundos base▶

O app pega o que você digita e cola dentro de uma query SQL. Se ele não separa "dado" de "comando", seu texto vira código que o banco executa.

SELECT * FROM products WHERE category = 'SEU_INPUT' AND released = 1

A aspa que fecha a string é tudo. Se você conseguir sair dela, você escreve SQL.

A escada (sempre nessa ordem) método▶
  1. Detectar — manda uma aspa '. Quebrou (500)? Tem injeção.
  2. Confirmar — entende a query e monta a lógica (OR 1=1).
  3. Explorar — comenta o resto com -- e extrai/burla.
  4. Documentar — request, resposta, impacto, remediação.

Regra de ouro: o menor payload que prova primeiro. Depois escala.

Payloads toque p/ copiar▶

1. Detectar — uma aspa. Resposta 500 = ouro.

'copiar

2. Retornar tudo — condição sempre verdadeira + comentar o resto.

' OR 1=1--copiar

3. Na URL (espaço vira +, e o -- ganha espaço depois):

'+OR+1=1--+-copiar

Login bypass — entrar como um usuário sem a senha (comenta a checagem):

USUARIO'--copiar

Troca USUARIO pelo alvo (ex: o admin). A senha pode ser qualquer coisa — ela é comentada.

Gotchas que derrubam todo mundo !▶

⚠ Espaço na URL quebra a request. Use + ou %20.

⚠ Comentário -- em MySQL precisa de espaço depois. Como o app cola uma aspa logo em seguida (--'), o comentário não "pega". Solução: -- - (na URL: --+-).

⚠ A aspa também é codificada: o navegador manda ' como %27. Mesmo payload.

⚠ 500 ≠ 400 ≠ 403. 500 é o banco engasgando (bom sinal). 400 "Protocol error" / 403 é transporte/infra, não o teu payload.

UNION attack roubar dados▶

Cola uma 2ª SELECT na query pra puxar dados de outras tabelas (users, senhas...).

⚠ 2 regras: (1) mesmo nº de colunas nas duas queries; (2) tipos compatíveis.

1. Contar colunas — ORDER BY até quebrar (quebrou no N → N-1 colunas):

' ORDER BY 1--copiar

...incrementa 2, 3, 4... até dar 500.

Ou com NULLs (adiciona até parar de dar erro; nº de NULLs = nº de colunas):

' UNION SELECT NULL,NULL,NULL--copiar

2. Achar a coluna de texto — põe um texto numa posição por vez:

' UNION SELECT 'a',NULL,NULL--copiar

Sem erro + o 'a' aparece na tela = essa coluna aceita texto.

3. Extrair dados reais — puxa colunas de outra tabela (nas posições de texto):

' UNION SELECT username,password,NULL FROM users--copiar

Na URL: espaços = +, fim = --+-.

Fluxo no Caido ferramenta▶

1. Abre o Caido, seleciona o projeto. Proxy escuta em 127.0.0.1:8083.

2. Workspace → Browser Launcher → Launch (abre o Chrome roteado pelo proxy).

3. Navega no alvo → tudo cai em Proxy → HTTP History.

4. Acha a request → botão direito → Send to Replay → edita e reenvia.

Se o Replay cuspir "Protocol error" em tudo (HTTP/2 enroscado): dispara pelo navegador — continua passando pelo proxy.

Debug: travou e não sabe por quê? Manda uma request limpa pra isolar transporte × payload.
